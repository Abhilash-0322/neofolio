# Abhilash Maurya — Portfolio

A cobalt dashboard-style portfolio for Abhilash Maurya, built with Next.js 14, React, TypeScript, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

The development server is configured for **http://localhost:5145**.

## Production build

```bash
npm run build
npm run start
```

The interface includes:

- Dark and light themes with a persistent theme toggle
- Responsive dashboard layout
- Projects, experience, core stack, and contact sections
- Open-to-work availability status
- Links to GitHub, LinkedIn, X, email, and project repositories
