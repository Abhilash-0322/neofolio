# Abhilash Maurya — Portfolio

A split-sidebar portfolio for Abhilash Maurya, a backend and AI systems developer focused on reliable APIs, cloud delivery, and useful AI products.

## Stack

- Next.js 14
- React 18
- TypeScript
- CSS

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5078](http://localhost:5078).

## Production build

```bash
npm run build
npm start
```

The page is responsive, uses semantic sections, and keeps external project links in the project cards.
