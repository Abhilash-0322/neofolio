# Abhilash Maurya — Portfolio

A personal portfolio for Abhilash Maurya, a backend and AI systems developer. The site presents selected work, experience, capabilities, and contact details in a warm burgundy/wine visual system with light and dark themes.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- Tailwind CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5123](http://localhost:5123).

## Production

```bash
npm run build
npm start
```

The production server also uses port `5123`.

## Content

Portfolio content is sourced from `information.txt`. Update project links, experience, and contact information in `app/page.tsx`.
