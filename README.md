# Abhilash Maurya — Portfolio

Editorial portfolio for Abhilash Maurya, a backend and AI systems developer. The site presents selected products, experience, capabilities, and contact details in a charcoal-and-paper visual system.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5131](http://localhost:5131).

## Production

```bash
npm run build
npm run start
```

The light/dark theme preference is saved in `localStorage`. Project links and profile details are maintained in `app/page.tsx`.
