# Abhilash Maurya — Ink Ledger

A finance-inspired portfolio for Abhilash Maurya, built around the visual language of a working ledger: warm paper, ink, ruled lines, and small signals of green for active status.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- `next-themes` for light and dark mode

## Run locally

```bash
npm install
npm run dev
```

The development server runs at [http://localhost:5110](http://localhost:5110).

## Production build

```bash
npm run build
npm run start
```

The site presents selected backend, AI systems, cloud, and fintech-oriented work, with direct links to project demos, GitHub, and contact channels.
