# Abhilash Maurya — Portfolio

A signal-orange, systems-minded portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14 + React 18
- TypeScript
- Tailwind CSS
- `next-themes` for system-aware light/dark themes
- Lucide React icons

## Run locally

```bash
npm install
npm run dev -- -p 5115
```

Open [http://localhost:5115](http://localhost:5115).

## Production build

```bash
npm run build
npm run start -- -p 5115
```

The site is a static portfolio experience with anchored sections for selected work, background, toolkit, and contact. Project links and contact details are sourced from `information.txt`.
