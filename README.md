# Abhilash Maurya — Neofolio

A responsive portfolio for backend and AI systems work, styled as a quiet
Gothic cathedral: parchment in light mode, midnight stone and stained-glass
accents in dark mode.

## Stack

- Next.js 14 App Router
- React 18 + TypeScript
- CSS-first responsive design with a persisted light/dark theme toggle

## Run locally

```bash
npm install
PORT=5087 npm run dev
```

Open [http://localhost:5087](http://localhost:5087).

The `dev` and `start` scripts default to port `5087`; `PORT` can override it.

## Production check

```bash
npm run build
PORT=5087 npm start
```
