# Abhilash Maurya — Olive Field Portfolio

Professional portfolio for Abhilash Maurya, a backend and AI systems developer focused on APIs, cloud infrastructure, AI agents, and retrieval-augmented systems. The Olive Field visual direction uses an editorial grid, organic olive accents, and a calm light/dark pairing.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- `next-themes` for light and dark mode
- Olive Field design system with responsive editorial cards

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5144](http://localhost:5144).

## Verify a production build

```bash
npm run build
```

## Content

Portfolio content is based on `information.txt` and `abhilash_python.pdf`, including experience at Innogeeks Club and Spearmint Technologies, selected projects, certifications, education, coding profiles, and contact links.

## Design notes

- Theme: Olive Field
- Theme modes: light and dark via the sun/moon control
- Availability: clearly marked as open to work for cloud, backend, and AI systems roles
- Production port: `5144`
