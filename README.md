# Skyline Dusk — Abhilash Maurya

A responsive, dusk-first portfolio for Abhilash Maurya, a backend and AI systems developer. The visual direction pairs a quiet editorial layout with a hand-built city skyline, warm dusk accents, and a daylight theme for a softer reading mode.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- CSS custom properties for the dual theme
- No image or icon dependency — the skyline and interface icons are CSS/SVG

## Run locally

```bash
npm install
npm run dev
```

The development server is pinned to [http://localhost:5124](http://localhost:5124).

## Commands

```bash
npm run dev    # start on port 5124
npm run build  # create a production build
npm run start  # serve the production build on port 5124
```

## Theme

The default `Skyline dusk` theme is stored as `dusk` in `localStorage`. Use the Daylight/Dusk control in the header to switch between the dark dusk palette and the light daylight palette.

## Content

Portfolio content is based on the supplied profile and resume materials. Project links point to Abhilash's public GitHub projects and available live deployments.
