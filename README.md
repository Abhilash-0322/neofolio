# Abhilash Maurya — Graphite Studio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer focused on cloud infrastructure, production-minded AI, and fintech-adjacent engineering.

## Stack

- Next.js 14.2 / React 18
- TypeScript
- Tailwind CSS
- next-themes
- Lucide icons

## Local development

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5112](http://localhost:5112).

## Production build

```bash
npm run build
npm run start
```

The resume is available at `/abhilash_python.pdf`. Portfolio content is sourced from `information.txt` and the accompanying resume.
