# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer. The site presents selected work, experience, focus areas, and contact details in a minimal black-and-gold visual system.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5140](http://localhost:5140).

## Production

```bash
npm run build
npm start
```

The site is configured to use port `5140` for both development and production start commands.
