# Abhilash Maurya — Portfolio

Midnight-indigo portfolio for Abhilash Maurya, a backend and AI systems developer focused on reliable APIs, agent workflows, and cloud infrastructure.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- `next-themes`

## Run locally

```bash
npm install
npm run dev
```

The site runs at [http://localhost:5118](http://localhost:5118).

## Build

```bash
npm run build
```

The portfolio content is sourced from `information.txt` and `abhilash_python.pdf`.
