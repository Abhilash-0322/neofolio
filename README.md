# Abhilash Maurya — Portfolio

A minimal rose-gold portfolio for Abhilash Maurya, a backend and AI systems developer working across APIs, cloud infrastructure, agents, and RAG.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5136](http://localhost:5136).

## Production

```bash
npm run build
npm run start
```

The site includes a light/dark theme toggle, responsive navigation, project links, experience, skills, and contact details sourced from `information.txt`.
