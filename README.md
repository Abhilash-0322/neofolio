# Abhilash Maurya — Portfolio

Professional portfolio for Abhilash Maurya, a backend and AI systems developer focused on APIs, cloud infrastructure, AI agents, and retrieval-augmented systems.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- `next-themes` for light and dark mode
- Northern lights aurora visual system

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5109](http://localhost:5109).

## Verify a production build

```bash
npm run build
```

## Content

Portfolio content is based on `information.txt` and `abhilash_python.pdf`, including experience at Innogeeks Club and Spearmint Technologies, selected projects, certifications, education, coding profiles, and contact links.
