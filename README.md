# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer based in Delhi NCR.

## Stack

- Next.js 14
- React 18
- TypeScript
- CSS with a small Tailwind-compatible setup

## Run locally

```bash
npm install
npm run dev
```

The development server is configured for [http://localhost:5155](http://localhost:5155).

## Production build

```bash
npm run build
npm run start
```

The site includes a quiet fog-grey visual system, responsive layouts, accessible external links, and a persistent light/dark theme toggle.
