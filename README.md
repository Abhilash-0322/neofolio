# Abhilash Maurya — Portfolio

A concrete-gallery portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- next-themes
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5114](http://localhost:5114).

## Build

```bash
npm run build
npm start
```

The site is intentionally image-light: the visual language is built from concrete tones,
grid lines, geometric forms, grain, and a high-contrast signal color. Content is sourced
from `information.txt` and `abhilash_python.pdf`.
