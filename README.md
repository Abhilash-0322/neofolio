# Abhilash Maurya — Portfolio

Gold-line finance-inspired portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- CSS with responsive light/dark themes

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5154](http://localhost:5154).

## Production

```bash
npm run build
npm run start
```

`npm run start` also uses port `5154`.

## Theme

The theme toggle stores the selected light/dark preference in `localStorage`. Project links, social links, and email CTAs are wired to the profile source material in `information.txt`.
