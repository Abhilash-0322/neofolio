# neofolio-5062

Swiss-grid mono portfolio for Abhilash Maurya — a backend and AI systems
developer working across APIs, agents, cloud infrastructure, and production
software.

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5062](http://localhost:5062).

## Highlights

- Responsive Swiss-inspired grid layout with a light/dark theme toggle
- Project, experience, skills, achievements, and coding profile sections
- Accessible skip link, semantic navigation, external-link safety attributes,
  and reduced-motion support
- Resume PDF available at `/abhilash_python.pdf`

Built with Next.js 14, React, TypeScript, Tailwind CSS, Framer Motion, and
next-themes.
# Neofolio 5058 — Railroad Timetable

Dual-theme portfolio for Abhilash Maurya.

- **Light:** Vintage railroad timetable (parchment grid, sepia ink, departure-board typography)
- **Dark:** Night express (midnight platform, amber lamps, signal red accents)

## Run

```bash
npm install
npm run dev
```

Dev server: [http://localhost:5058](http://localhost:5058)

Theme preference is persisted via `next-themes` (`neofolio-5058-theme`).
