# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer
focused on cloud infrastructure, APIs, agent workflows, and RAG systems.

## Stack

- Next.js 14
- React 18
- TypeScript
- CSS with a responsive magenta studio visual system

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5147](http://localhost:5147).

## Production

```bash
npm run build
npm run start
```

The site includes a light/dark theme toggle, responsive layouts, selected
projects, work history, and contact links. Project and profile source material
is kept in `information.txt`; the resume is available as `abhilash_python.pdf`.
