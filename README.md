# Neofolio

A responsive oceanic portfolio for Abhilash Maurya, built with Next.js App Router. The visual system uses deep-water tones, aqua accents, and slow CSS wave motion.

## Stack

- Next.js 14 + TypeScript
- CSS-first responsive design

## Run

```bash
npm install
PORT=5068 npm run dev
```

Open [http://localhost:5068](http://localhost:5068).

The `dev` and `start` scripts default to port `5068`; `PORT` can override it.

## Production check

```bash
npm run build
PORT=5068 npm start
```
