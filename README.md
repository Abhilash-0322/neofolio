# Abhilash Maurya — Portfolio

A responsive personal portfolio for Abhilash Maurya, built with Next.js 14, React, TypeScript, Tailwind CSS, and a small custom CSS design system.

## Direction

The visual language is **Teal Harbor**: deep water, bright signal green, and restrained surfaces for a calm technical portfolio. The site ships with a persistent light/dark theme toggle and a clear **OPEN TO WORK** status.

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5139](http://localhost:5139).

## Production

```bash
npm run build
npm run start
```

`next.config.mjs` uses the standalone output mode for simple deployment to a container or Node host.

## Content

Project and profile details are sourced from `information.txt`. Update the content arrays in `app/page.tsx` and visual tokens in `app/globals.css` as the portfolio evolves.
