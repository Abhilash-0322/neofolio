# neofolio-5032 (design-5032)

Story-driven portfolio for Abhilash Maurya — **Arctic frost** light theme and **dark glacier** mode via `next-themes`.

## Stack

- Next.js 14 + TypeScript
- Tailwind CSS + CSS theme tokens
- `next-themes` class-based toggle
- Framer Motion + GSAP ScrollTrigger
- React Three Fiber / Drei for ambient 3D visuals

## Run

```bash
npm install
npm run dev
```

Dev server: **http://localhost:5032**

## Deploy

Optimized for Vercel default deployment.
