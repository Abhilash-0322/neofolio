# Abhilash Maurya — Portfolio

A warm, editorial portfolio for Abhilash Maurya, a backend and AI systems developer working across APIs, agent workflows, RAG, and cloud infrastructure.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- Tailwind CSS / custom CSS

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5138](http://localhost:5138).

## Production

```bash
npm run build
npm run start
```

The site includes a light/dark theme toggle, responsive layouts, project links, experience, skills, and contact details.
