# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer focused on APIs, cloud infrastructure, agentic workflows, and RAG products.

## Stack

- Next.js 14 / React 18
- TypeScript
- Tailwind CSS and custom CSS
- Dual light/dark theme with persisted preference

## Run locally

```bash
npm install
npm run dev
```

The development server is configured for **http://localhost:5156**.

## Production

```bash
npm run build
npm run start
```

The site includes selected project links, contact actions, responsive navigation, and an `Open to work` status.
