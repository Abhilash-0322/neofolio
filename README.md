# Abhilash Maurya — Portfolio

A walnut-study inspired portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14 App Router
- React 18 + TypeScript
- Custom CSS with a light/dark theme toggle
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5158](http://localhost:5158). For a production check:

```bash
npm run build
npm run start
```

## Design notes

The interface uses a warm walnut, paper, and ink palette with an editorial serif display face. Theme preference is saved in `localStorage`, and the page is responsive without a UI framework.
