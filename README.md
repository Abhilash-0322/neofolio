# Abhilash Maurya — Sage botanical portfolio

Portfolio variant on branch `portfolio/design-5119`, shaped around a calm
botanical sage palette and a clear “OPEN TO WORK” signal. The page presents
Abhilash’s backend, AI systems, cloud, projects, experience, and contact
details in a responsive single-page layout.

## Stack

- Next.js 14.2, React 18, TypeScript
- Tailwind CSS and `lucide-react`
- `next-themes` for persisted light/dark theme switching
- Source material from `information.txt` and `abhilash_python.pdf`

## Commands

```bash
npm install
npm run dev    # http://localhost:5119
npm run build
```

No development server is required for the production build.
