# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer focused on dependable APIs, cloud infrastructure, and AI products that work beyond demos.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5132](http://localhost:5132).

## Production

```bash
npm run build
npm start
```

`npm start` also uses port `5132`. The site includes a persisted light/dark theme toggle and responsive navigation.
