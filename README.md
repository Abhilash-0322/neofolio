# Abhilash Maurya — Portfolio

A terracotta studio portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS / PostCSS
- CSS custom properties for the light and dark themes

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5117](http://localhost:5117).

## Production build

```bash
npm run build
npm run start
```

## Notes

- The theme toggle persists the selected light or dark theme in `localStorage`.
- Project links and contact details are sourced from `information.txt`.
- The page is responsive and does not require a CMS or external API.
