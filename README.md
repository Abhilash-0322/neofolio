# Abhilash Maurya — Portfolio

A plum-evening portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14 · React 18 · TypeScript
- CSS custom properties for a dual dark/light theme
- No UI library or runtime animation dependency

## Run locally

```bash
npm install
npm run dev
```

The development server uses port **5153**:

```bash
open http://localhost:5153
```

## Production check

```bash
npm run lint
npm run build
npm run start
```

The site includes selected project links, experience, technical toolkit, open-to-work status, and contact links. Theme preference is stored in `localStorage`.
