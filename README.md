# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer based in Delhi NCR.

## Stack

- Next.js 14 + React 18
- TypeScript
- CSS with a responsive, dual-theme design system

## Run locally

```bash
npm install
npm run dev
```

The site runs at [http://localhost:5134](http://localhost:5134).

## Production

```bash
npm run build
npm start
```

The portfolio highlights selected AI, backend, and cloud projects, includes a filterable work log, downloadable resume, and persists the light/dark theme preference in local storage.
