# Abhilash Maurya — Portfolio

A small, stationery-inspired portfolio for Abhilash Maurya, a backend and AI
systems developer. Built with Next.js 14, React, TypeScript, and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

The development server is configured for [http://localhost:5146](http://localhost:5146).

## Production build

```bash
npm run build
npm run start
```

## Design notes

- Warm paper, ink, tape, and notebook-grid details make the light theme feel
  tactile without hiding the content.
- The theme toggle switches between the default cream stationery palette and a
  deep blue night palette without changing the layout.
- The page is responsive, keyboard-friendly, and uses reduced-motion preferences
  for the marquee and hover treatments.

## Content

Project links and profile details are based on `information.txt`. Update the
project data in `app/page.tsx` and visual tokens in `app/globals.css` as the
portfolio evolves.
