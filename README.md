# Neofolio — Pop Art Halftone

A story-driven portfolio for Abhilash Maurya, styled like a high-contrast pop-art
print: halftone dots, punchy primary colors, hard shadows, and animated editorial
panels.

## Stack

- Next.js 14 App Router + TypeScript
- Tailwind CSS with custom pop-art tokens
- Framer Motion for section reveals

## Local development

```bash
npm install
npm run dev
```

The development server runs on **http://localhost:5072**. The production start
script uses the same port.

## Verification

```bash
npm run lint
npm run build
```

## Deployment

The app is Vercel-ready. Build output is generated by `next build`; `.next/` is
ignored and should not be committed.
