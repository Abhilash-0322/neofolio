# Abhilash Maurya — Portfolio

A paper-white editorial portfolio for Abhilash Maurya, a backend and AI systems developer based in Delhi NCR.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- CSS with responsive layout, system details, and light/dark themes

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5121](http://localhost:5121).

## Production

```bash
npm run build
npm run start
```

The site includes selected project work, experience, capabilities, recognition, and direct contact links. Theme preference is stored locally and respects the system preference on first visit.
