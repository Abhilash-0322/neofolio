# neofolio-5046 — Luxury watch

Dual-theme portfolio variant: **champagne** (light) and **onyx** (dark), with `next-themes` and a crown-style toggle in the header.

## Run

```bash
npm install
npm run dev
```

Dev server: [http://localhost:5046](http://localhost:5046)

Theme preference is stored under `neofolio-5046-theme` in local storage.
