# Abhilash Maurya — Portfolio

A Pine-themed portfolio for Abhilash Maurya, built with Next.js 14, React, TypeScript, Tailwind CSS, and Lucide icons.

## Local development

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5148](http://localhost:5148).

## Production

```bash
npm run build
npm run start
```

The page includes a persistent day/night theme toggle, selected projects, experience, skills, and contact links. Edit `app/page.tsx` for content and `app/globals.css` for the visual system.

## Deployment

The project is ready for a standard Next.js deployment on Vercel or any Node host that supports Next 14.
