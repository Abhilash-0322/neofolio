# Abhilash Maurya — Portfolio

Aurora slate portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

The development server is configured for **http://localhost:5159**.

## Production build

```bash
npm run build
npm start
```

## Notes

- Dark/light theme preference is stored in `localStorage`.
- Project, experience, and contact content lives in `app/page.tsx`.
- Visual styling and responsive layouts live in `app/globals.css`.
