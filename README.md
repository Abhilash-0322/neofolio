# neofolio 5080

An accordion FAQ-style portfolio for Abhilash Maurya, built with Next.js 14, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5080](http://localhost:5080).

## Scripts

- `npm run dev` — start the development server on port 5080
- `npm run build` — create a production build
- `npm run start` — serve the production build on port 5080
- `npm run lint` — run Next.js lint checks

## Design

The page is organized as a set of expandable questions. The FAQ interaction keeps a long-form portfolio scannable while still giving projects, experience, technical skills, and contact details room to breathe. It uses a warm paper palette, editorial typography, and small rust accents to make the interface feel like a considered personal index rather than a dashboard.
