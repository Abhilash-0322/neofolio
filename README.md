# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer.
The interface uses a cyan laboratory visual language with a dark/light theme
toggle and a responsive Next.js 14 app-router layout.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5151](http://localhost:5151).

## Production build

```bash
npm run build
npm run start
```

The production server also runs on port `5151`. No environment variables are
required.

## Content

Project and profile source material is kept in `information.txt`. Update the
data arrays in `app/page.tsx` when adding projects or experience.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
