# Abhilash Maurya — Portfolio

An electric-violet portfolio for Abhilash Maurya, a backend and AI systems developer.

Built with Next.js 14, React 18, TypeScript, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5130](http://localhost:5130).

## Production

```bash
npm run build
npm run start
```

The site supports light and dark themes through the theme toggle in the header. Project and social links are sourced from `information.txt`.
