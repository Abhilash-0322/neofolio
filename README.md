# Abhilash Maurya — Portfolio

An employer-ready portfolio for Abhilash Maurya, a backend and AI systems developer focused on production APIs, agent workflows, and cloud infrastructure.

## Theme

The visual language is **Art Deco Gold Geometry**:

- warm parchment and ink surfaces for a timeless editorial base
- gold rules, corner brackets, diamonds, and concentric geometry as the signature motif
- serif display typography paired with compact uppercase navigation
- responsive project cards, experience timeline, credentials, and direct contact CTA
- light/dark themes powered by `next-themes`, with the gold system preserved in both modes

## Run locally

Requires Node.js 18.17+.

```bash
npm install
npm run dev -- -p 5108
```

Open [http://localhost:5108](http://localhost:5108).

## Production build

```bash
npm run build
npm run start -- -p 5108
```

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- `next-themes`
