# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer focused on cloud infrastructure, APIs, AI agents, RAG, and fintech-oriented engineering.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- Tailwind CSS
- next-themes

## Getting started

```bash
npm install
npm run dev -- -p 5113
```

Open [http://localhost:5113](http://localhost:5113).

## Production build

```bash
npm run build
npm run start -- -p 5113
```

The site uses a Lavender dusk visual system with a dark default theme, responsive layouts, and a light/dark theme toggle.
