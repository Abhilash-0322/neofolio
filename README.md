# Abhilash Maurya — Watercolor Portfolio

A warm, paper-textured portfolio for Abhilash Maurya, focused on backend engineering, practical AI systems, and cloud infrastructure.

## Stack

- Next.js 14 App Router
- React 18 + TypeScript
- CSS watercolor palette with responsive layout and reduced-motion support

## Run locally

```bash
npm install
PORT=5089 npm run dev
```

The production server uses port `5089` by default:

```bash
npm run build
npm start
```

## Content

Profile and project details are sourced from `information.txt`. External links point to Abhilash's live projects and public profiles.
