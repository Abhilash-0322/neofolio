# Abhilash Maurya — Portfolio

A lilac, editorial portfolio for Abhilash Maurya, a backend and AI systems developer based in Delhi NCR.

## Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS / custom CSS

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5143](http://localhost:5143).

## Production build

```bash
npm run build
npm run start
```

## Design notes

- Lilac academic visual language with paper textures, editorial serif type, and research-note details.
- Light and dark themes are available from the navigation toggle and persist in local storage.
- Responsive layout covers projects, work history, toolkit, contact details, and external links.
- The page is intentionally dependency-light and uses inline SVG icons.
