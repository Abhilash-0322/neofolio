# Abhilash Maurya — Portfolio

A calm, coral reef-inspired portfolio for Abhilash Maurya, built with Next.js 14, TypeScript, Tailwind CSS, and `next-themes`.

## Run locally

```bash
npm install
npm run dev
```

The development server runs at [http://localhost:5111](http://localhost:5111).

## Production build

```bash
npm run build
npm run start
```

## Highlights

- Responsive portfolio layout with selected projects, experience, toolkit, and contact details.
- Light and dark themes with system preference support.
- Uses the source material in `information.txt` and `abhilash_python.pdf`.
