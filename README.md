# Abhilash Maurya — Portfolio

Midnight copper portfolio for Abhilash Maurya, a backend and AI systems developer based in Delhi NCR.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- `next-themes` for light/dark mode
- Lucide React icons

## Run locally

```bash
npm install
npm run dev -- -p 5085
```

Open [http://localhost:5085](http://localhost:5085).

## Build

```bash
npm run build
```

The page content is grounded in `information.txt` and `abhilash_python.pdf`.
