# Abhilash Maurya — Portfolio

A personal portfolio for Abhilash Maurya, a backend and AI systems developer based in Delhi NCR.

The site uses an editorial **Brick loft** visual direction: warm paper tones, dark industrial panels, blueprint lines, and rust-orange accents. It includes a light/dark theme switcher and a responsive layout for mobile through desktop.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- CSS with custom properties (no UI framework)

## Local development

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5152](http://localhost:5152).

## Production

```bash
npm run build
npm run start
```

The production server also runs on port `5152`.

## Content

Project and profile source material lives in [`information.txt`](./information.txt). Project links and contact details are rendered from `app/page.tsx`.
