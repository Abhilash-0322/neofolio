# Abhilash Maurya — Neofolio

A dark, editorial portfolio for Abhilash Maurya, a backend and AI systems developer. The visual language is a **cyber mesh lattice**: technical mono labels, a luminous node network, acid-green highlights, and cyan/orange system accents.

## Stack

- Next.js 14
- React 18
- TypeScript
- CSS (custom responsive system; no UI framework)

## Run locally

Requires Node.js 18.17+.

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5070](http://localhost:5070).

## Production build

```bash
npm run build
npm run start
```

`start` also uses port `5070`.

## Content

Project links and profile details are sourced from `information.txt`. Update `app/page.tsx` to change the displayed projects, capabilities, social links, or contact details.
