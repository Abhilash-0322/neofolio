# Abhilash Maurya — Portfolio

A warm, editorial portfolio for Abhilash Maurya, a backend and AI systems
developer building production-minded APIs, agent workflows, and cloud
infrastructure.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- CSS with a responsive Sand linen visual system

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5129](http://localhost:5129).

## Production

```bash
npm run build
npm start
```
