# neofolio / 5060

Obsidian glass fintech portfolio for Abhilash Maurya — a Next.js 14, TypeScript, Tailwind, and next-themes single-page site.

## Run locally

```bash
npm install
npm run dev
```

The dev server runs on port 5060. Use `npm run build` to create the production build.

## Direction

The interface uses a dark-first obsidian palette, lime signal accents, translucent glass panels, and a fintech operations-console visual language. Light mode is available from the header toggle.
