# Abhilash Maurya — Portfolio

A warm ivory, editorial portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5150](http://localhost:5150).

## Production

```bash
npm run build
npm run start
```

The site supports light and dark themes using the theme control in the header. Content and external project links are maintained in `app/page.tsx`.
