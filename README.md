# Abhilash Maurya — Portfolio

A navy pinstripe portfolio for Abhilash Maurya, a backend and AI systems developer focused on APIs, cloud infrastructure, agent workflows, and RAG systems.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- Tailwind CSS / PostCSS

## Run locally

```bash
npm install
npm run dev
```

The development server runs on **[http://localhost:5133](http://localhost:5133)**.

## Production

```bash
npm run build
npm start
```

The site includes a persisted light/dark theme toggle, responsive layouts, project links, experience, and contact/social links.
