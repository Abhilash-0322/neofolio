# Abhilash Maurya — Portfolio

A Copper circuit portfolio for Abhilash Maurya, a backend and AI systems developer focused on cloud infrastructure, APIs, agents, RAG, and fintech-oriented engineering.

## Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- `next-themes`
- `lucide-react`

## Local development

```bash
npm install
npm run dev -- -p 5120
```

Open [http://localhost:5120](http://localhost:5120).

## Production build

```bash
npm run build
npm start
```

## Content

Project links and professional details are sourced from `information.txt`. Update the project data in `app/page.tsx` when adding new work.
