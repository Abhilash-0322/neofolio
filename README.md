# Abhilash Maurya — Portfolio

An editorial, amber-toned portfolio for Abhilash Maurya, a backend and AI systems developer based in Delhi NCR.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- Tailwind CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5126](http://localhost:5126).

## Production build

```bash
npm run build
npm start
```

`npm start` also uses port `5126`.

## Design notes

- Warm amber and paper palette with an ink-dark alternate theme.
- Light/dark preference is persisted in `localStorage` and respects the system theme on first visit.
- Responsive sections cover selected work, capabilities, experience, and contact.
- External project, GitHub, LinkedIn, and email links are wired to the supplied source material.
