# Abhilash Maurya — Neon Mint Terminal

A terminal-inspired portfolio for Abhilash Maurya, a backend and AI systems developer. The visual system uses a deep green / neon mint palette, responsive grid details, and a persistent light/dark theme switch.

## Stack

- Next.js 14 App Router
- React 18
- TypeScript
- CSS with responsive layout and theme variables

## Run locally

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5122](http://localhost:5122).

## Production build

```bash
npm run build
npm run start
```

## Content

The page includes selected work, current experience, certifications, technical skills, external project links, and contact actions. The theme preference is stored in `localStorage` as `portfolio-theme`.
