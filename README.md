# Abhilash Maurya — Portfolio

A responsive personal portfolio for Abhilash Maurya, a backend and AI systems developer based in Delhi NCR.

## Stack

- Next.js 14 App Router
- React 18 + TypeScript
- Tailwind CSS with custom CSS design tokens
- Glacier-white light theme with persisted dark-mode toggle

## Local development

```bash
npm install
npm run dev
```

The development server runs on [http://localhost:5157](http://localhost:5157).

## Production build

```bash
npm run build
npm start
```

## Project structure

- `app/page.tsx` — portfolio sections and reusable inline icon/project components
- `app/globals.css` — responsive layout, motion, theme variables, and visual system
- `app/layout.tsx` — site metadata and root layout
- `information.txt` — source material used for portfolio content
