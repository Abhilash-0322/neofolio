# Neofolio 5058 — Railroad Timetable

Dual-theme portfolio for Abhilash Maurya.

- **Light:** Vintage railroad timetable (parchment grid, sepia ink, departure-board typography)
- **Dark:** Night express (midnight platform, amber lamps, signal red accents)

## Run

```bash
npm install
npm run dev
```

Dev server: [http://localhost:5058](http://localhost:5058)

Theme preference is persisted via `next-themes` (`neofolio-5058-theme`).
