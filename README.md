# Neofolio 5050 — Film Noir

Dual-theme portfolio for Abhilash Maurya.

- **Silver screen (light):** high-contrast silver projection palette
- **Noir (dark):** venetian-blind shadows and amber highlights
- Theme toggle persists via `next-themes` (`neofolio-5050-theme`)

## Run

```bash
npm install
npm run dev
```

Dev server: [http://localhost:5050](http://localhost:5050)
