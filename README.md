# Abhilash Maurya — Portfolio

A Storm grey systems portfolio for Abhilash Maurya, a backend and AI systems developer. The site is deliberately quiet, structured, and signal-led: shipped work first, clear capabilities second, and a direct path to start a conversation.

## Stack

- Next.js 14 App Router
- React 18 + TypeScript
- CSS custom properties for the dual dark/light theme
- No external UI or animation runtime

## Run locally

```bash
npm install
npm run dev
```

The development server runs on **http://localhost:5137**. Production uses the same port:

```bash
npm run build
npm start
```

## Design direction

The Storm grey system uses graphite surfaces, restrained borders, mono metadata, and an acid signal green for availability and emphasis. The theme toggle persists the selected mode in `localStorage`, while the layout remains usable without JavaScript.

## Content

Profile source material lives in `information.txt`. Project links and portfolio copy are organized at the top of `app/page.tsx` for quick updates.
