# Abhilash Maurya — Portfolio

A cloud-white, editorial portfolio for Abhilash Maurya: backend developer, AI systems builder, and cloud engineer.

## Stack

- Next.js 14 / React 18
- TypeScript
- Custom responsive CSS
- Lucide icons
- Light and dark theme toggle with local persistence

## Run locally

```bash
npm install
npm run dev
```

The development server is configured for **http://localhost:5141**.

## Production

```bash
npm run build
npm start
```

The page is fully static from the client’s perspective and does not require an API or database. Project links and contact details are sourced from `information.txt`.
