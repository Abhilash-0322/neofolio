# Abhilash Maurya — Portfolio

A frost-glass Nordic portfolio for Abhilash Maurya, a backend and AI systems developer.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- `next-themes`

## Run locally

```bash
npm install
npm run dev
```

The site runs on [http://localhost:5116](http://localhost:5116).

## Production build

```bash
npm run build
npm run start
```

## Content

Portfolio source material lives in `information.txt`. Update the project and profile arrays in `app/page.tsx` when adding new work.
