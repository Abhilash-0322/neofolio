# Abhilash Maurya — Portfolio

Personal portfolio for Abhilash Maurya, a backend and AI systems developer focused on cloud infrastructure, APIs, agent workflows, and RAG systems.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

The site runs on [http://localhost:5149](http://localhost:5149).

## Production

```bash
npm run build
npm run start
```

The visual system is built around a silver aerospace / flight-deck language with a dark default theme and a light theme toggle. Project and contact links are sourced from `information.txt`.
